# 🎨 Creative Agency Portfolio Template

A modern, responsive HTML5 template designed for creative agencies, design studios, and freelance portfolios. Built with Bootstrap, featuring smooth animations and interactive elements.

## ✨ Features

- **Responsive Design** - Mobile-first approach, works on all devices
- **Bootstrap 5** - Latest Bootstrap framework for consistent styling
- **Smooth Animations** - CSS animations and transitions for engaging UX
- **Magnific Popup** - Beautiful image galleries and lightbox functionality
- **Swiper Carousel** - Touch-enabled carousel for showcasing projects
- **Font Awesome Icons** - Extensive icon library
- **Multiple Layouts** - Variant homepage layouts included
- **SEO Optimized** - Meta tags and semantic HTML
- **Fast Performance** - Minified assets and optimized images
- **Easy to Customize** - Well-organized HTML structure and CSS

## 🚀 Quick Start

### Prerequisites
- Any modern web browser
- Text editor (VS Code, Sublime Text, etc.)
- Optional: Local web server (Python, Node.js, or Live Server extension)

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/MrShadowRIFAT/QRKLRMF-Agency_Portfolio_Template.git
cd QRKLRMF-Agency_Portfolio_Template
```

2. **Open in browser:**
   - Simply open `index.html` in your browser, or
   - Use a local web server for better development experience

3. **With Python 3:**
```bash
python -m http.server 8000
# Visit http://localhost:8000
```

4. **With Node.js:**
```bash
npx http-server
```

## 📝 Usage

### Customization

1. **Edit HTML Files** - Update content in `.html` files
2. **Modify Styles** - Edit `assets/css/style.css` for custom styling
3. **Update Images** - Replace images in `assets/img/`
4. **Change Fonts** - Modify font files in `assets/fonts/`
5. **Add JavaScript** - Extend functionality in `assets/js/`

### Key Sections

- **Homepage** - Multiple layout options available (`index.html`, `index-2.html`, `index-3.html`)
- **About** - Showcase your agency or personal story
- **Services** - Highlight your services and expertise
- **Portfolio** - Display past projects with details
- **Team** - Introduce team members
- **Blog** - Share articles and insights
- **Contact** - Get in touch form and information
