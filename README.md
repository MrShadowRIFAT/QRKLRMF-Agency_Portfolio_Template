# 🎨 Creative Agency Portfolio Template

Modern, responsive HTML5 template for creative agencies and portfolios. Built with Bootstrap 5, animations, and interactive elements.

## ✨ Features

- Fully responsive design
- Bootstrap 5 framework
- Smooth animations & effects
- Image galleries & lightbox
- Multiple homepage layouts
- SEO optimized
- Easy to customize

## 🚀 Quick Installation

### 1. Fork This Repository
Click the **Fork** button at the top-right of this GitHub repo to create your own copy.

### 2. Deploy to Vercel
- Go to [Vercel.com](https://vercel.com)
- Click **Add New** → **Project**
- Import your forked GitHub repository
- Click **Deploy** (no config needed - it auto-detects)
- Your site goes live instantly! 🎉

### 3. Edit Files from GitHub
- Open any `.html` file in your forked repo
- Click the ✏️ **Edit** button
- Make changes and commit directly
- Vercel auto-deploys your changes

### Local Development
```bash
git clone https://github.com/YOUR_USERNAME/QRKLRMF-Agency_Portfolio_Template.git
cd QRKLRMF-Agency_Portfolio_Template
python -m http.server 8000
```

## 📁 Pages

- `index.html` - Homepage (3 variants available)
- `about-us.html`, `about-me.html` - About pages
- `services-details.html` - Services showcase
- `team.html`, `team-details.html` - Team pages
- `blog.html`, `blog-details.html` - Blog
- `project-details.html` - Portfolio
- `contact.html` - Contact form

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5
- Swiper Carousel
- Font Awesome Icons
- Magnific Popup

## 📝 Customization

1. Edit HTML files for content
2. Modify `assets/css/style.css` for styling
3. Replace images in `assets/img/`
4. Update fonts in `assets/fonts/`
